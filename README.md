# EduGenie – Google Gemini Powered Learning Assistant

## 📌 Project Description

EduGenie is an AI-powered learning assistant designed to help students understand academic concepts easily. It uses Google Gemini API to provide simple and interactive answers to students' questions.

## 🎯 Objectives

- Help students clear their academic doubts.
- Provide simple explanations for difficult concepts.
- Make learning more interactive using AI.
- Provide a user-friendly web interface.

## 🚀 Features

- AI-powered question answering
- Simple concept explanations
- Interactive learning assistance
- Web-based user interface
- Google Gemini AI integration

## 🛠️ Technologies Used

- Python
- FastAPI
- Google Gemini API
- HTML
- CSS
- Jinja2
- Uvicorn

## 👩‍💻 Project

Developed as an academic project to demonstrate the use of Generative AI in education.
